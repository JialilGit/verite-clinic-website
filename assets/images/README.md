# Images Directory

This directory is intended for image assets used in the R Brows & Beyond template.

## Usage
Replace the placeholder images in the HTML files with actual images from this directory.

## Recommended Image Specifications
- Hero image: Landscape orientation, minimum 1920x1080px
- Service cards: Square or 4:3 ratio, minimum 800x600px
- About/CEO image: Portrait orientation, minimum 600x800px
- All images should be web-optimized (compressed, appropriate format)

## Placeholder Images
The template currently uses:
- Via.placeholder.com for service cards and about image
- CSS background for hero image (semi-transparent overlay)

When replacing, maintain the same aspect ratios to ensure layout consistency.

## Image Optimization Tips
- Use WebP format for better compression
- Implement lazy loading (already in template via loading="lazy" attribute)
- Consider using responsive images (srcset) for different screen sizes
- Compress images without noticeable quality loss
